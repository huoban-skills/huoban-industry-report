# 检索通则

有无一手访谈都适用。总原则见 SKILL.md 工作流程第 3 步，本文件只管具体怎么查、查到哪停。

## 必查三类

触发条件是"这句话凭什么可信"，不是章节位置：

1. 可核实的客观事实（数字／年份／政策／行业通行规则／主要玩家）；
2. 素材没覆盖但报告结构需要的内容；
3. 受访者的全行业断言——交叉验证不了就降级成"受访者认为"。

**不必查**：个案经验、公司内部做法、灰色环节真实操作——如实写、标口径。

## 先扩口径，再下"资料少"的结论

很多行业没有统一名称和统计口径。**"查不到全国统计" ≠ "没有公开资料"**——把后者当结论写进报告之前，必须先做两层扩展：

- **口径扩展**：不只搜用户给的叫法，并行查行业正式名称、市场俗称、相邻服务名、职业名、监管与采购口径（如"家庭教育陪伴"→"家庭教育指导服务 / 家庭教育指导师 / 家长教育 / 政府购买服务"）。
- **证据类型扩展（渠道六类）**：

  | 渠道类型 | 拿什么 |
  |---|---|
  | 官方统计与政策（部委、统计局、发布会） | 规模数字、政策年份 |
  | 行业协会 / 披露文件（年报、行业报告、招股书、政府采购公告） | 行业结构、利润率、分配机制、真实买家与金额 |
  | 垂直媒体（开工前先认出该行业的头部垂直媒体是谁） | 行业动态、深度报道、从业者原话 |
  | 司法与监管（裁判文书、监管通报、处罚公告） | 灰色环节、真实纠纷、合规底线 |
  | 企业侧（官网、注册信息、招聘 JD、电商价格） | 主体画像、真实报价、岗位分工 |
  | 学术与调研（论文、地方课题） | 没有官方统计时的替代口径 |

  地方样本、单个项目照写，标"局部观察 / 单一项目口径"，不冒充全国事实。

**搜不到 ≠ 没有，先换三招**：①长查询拆成"主体 + 单一事实"的短查询分头搜；②限定该行业的垂直媒体再搜一轮；③涉外或涉国际评级的行业换英文关键词搜权威源。三招用完仍无果，背景性数字写"无公开资料"；落在 stat 卡或关键结论上的数字还有第三条路——见下方「拆变量测算」。

## 先画证据地图、一次查完

先把会落进正文的条目列成清单（stat 卡数字 + 政策年份），每条同时标"该去哪类源找"，再查；别边写边零散查。**全面的判据是用到的渠道类型 ≥ 3 类**，不是搜索条数多。

**控 token 的漏斗**：

1. **第一轮广搜只初筛**——看标题、摘要、机构和年份，不逐页精读；
2. **筛出真正落进正文的高价值来源**（默认 12–18 个）再打开，PDF 只定位相关页；
3. **每个来源只记一行**「结论｜年份｜覆盖范围｜来源｜URL」，不把网页长文拖进上下文；子任务同样只回「事实 + 出处 URL」一行一条；
4. **停的信号**：连续两个新来源没有新增事实就停该分支；第二轮仍补不上的，标成具体的证据缺口（缺的是什么统计、什么样本），不无限搜下去。

控的是精读与回传，**不是检索广度**——叫法存疑先回上一节扩口径。

## 来源分级：线索和依据分开

- **一级**（官方统计与政策、行业协会、披露文件）→ 硬数字优先用；
- **二级**（头部垂直媒体、大媒体深度报道）→ 可落笔、标来源；
- **三级**（知乎专栏、自媒体、论坛）→ **只当线索不当依据**，从中发现的事实升级到一、二级验证后才可写，升不了就标"业内说法，未经证实"或不写；
- SEO 农场文与无署名转载直接排除。

**硬数字必须开原文核对**：搜索结果的摘要是机器转述，可能走样——凡进 stat 卡、时间轴、加粗结论的数字／年份／名单，打开来源页确认原文再落笔；软性背景可用摘要。原文打不开或与摘要不符，换来源或标"转述，未见原文"。核对时连指标定义一起核：同名指标在不同机构的统计口径可能差得很远（统计范围、是否含某类主体），数字与口径一起落笔。

**三方报告绝口不提的维度反向补查**：行业报告普遍报喜不报忧——只谈空间不谈竞争、只谈增速不谈利润，通篇不提的地方往往正是有问题的地方，对这些维度单独补一轮检索，别默认"没写就是没事"。

## 拆变量测算：查不到统计时的第三条路

前提：两层扩口径与换三招都做完仍无公开统计，且这个数落在 stat 卡或关键结论上。很多长尾行业没人有动力统计，"无公开统计"四个字对读者没用，一个标明假设的量级估算才有用。

- **把查不到的数拆成查得到的变量再相乘**：需求侧「目标客户数 × 渗透率 × 消费频次 × 客单价」，或供给侧「主体数量 × 单主体产出」。某个变量仍查不到就再拆一层，拆到有公开数据或可靠常识为止。
- **每个变量标出处**：查到的标来源；假设的写明"假设"并给依据（对标成熟市场、受访者口径、常识推算）。关键假设拿不准就给区间，不给单点数。
- **写清算出来的是天花板还是当前盘子**：渗透率取饱和值算的是潜在空间，取当前值算的是现状；口径规则见 framework「业务规模」。
- **测算结果只用于量级判断**（这是百亿还是十亿的生意），进报告须标"测算值，非统计数据"，stat 卡面写明关键假设，不得用来支撑精确结论。

## 查到哪停

停的标准不是"搜到了"，而是"这个数够格进报告"——来源可靠、口径与时点清楚、追问过"有没有更新的一版"（时间轴历史年份除外）、硬数字核过原文；大盘数字另需两个独立来源对上。够格即停，不为更完美再挖；软事实不交叉验证；查不到写"无公开统计"，不为填满而编。

数字对不上时**先怀疑口径和时点、再怀疑真伪**：能排成时间演变就按演变呈现、各标时点，不许挑一个当唯一真相；真冲突取更权威一方并注明另一说。

「发展阶段」「业务规模」两节的取数细则见 framework.md；无一手访谈时的逐节留白规则见 desk-research.md。
