## 详情

### 1. 新增: 访谈企业脱敏

报告会在团队内外流转，访谈对象的身份不该跟着走。铁律新增一条：公司全称、简称、品牌名、受访人姓名不出现在标题、正文、图内文字、图注、页脚和文件名里，统一写「访谈企业」，多家写「访谈企业 A / B」，人写岗位。能反推出是谁的线索（精确地址、独家产品名、「当地唯一一家」）同样抹掉。公开资料里的第三方企业照常写名。

执行上分两层：第 1 步通读素材时记下脱敏名单，第 5 步 `finalize.py --redact 名1,名2` 全文查零命中，命中即 FAIL；名单覆盖不到的间接线索进人工自检清单。名单走命令行参数，不落成文件，避免客户名跟着交付目录走。

### 2. 新增: 实物照片

「图与文字的分工」加一类「该用照片」：读者没见过的实物。framework.md 新增「实物照片」一节，写明放什么、放哪里、从哪来、图注怎么写、查不到就不放。不用访谈企业自己的照片和带其名称字样的照片，与脱敏一致。

报告是单文件交付，照片必须内嵌。`scripts/embed_photo.py` 把图压到宽 1200、约 300 KB 以内，输出带图号占位和「图片来源」的 `figure.photo` 片段。照片与 SVG 图共用一套图号。`check_report.py` 新增两项 FAIL：`<img>` 不是 data URI、照片图注没有「图片来源」。`figures/` 仍只导出 SVG。

### 3. 修复: 手机端字号

模板原先以 `<title>` 开头，没有 `<head>` 和 viewport 声明，手机浏览器按桌面宽度渲染再整页缩小，字缩到原来的四成左右。模板补上 doctype、charset 和 viewport；新增 640px 以下的样式：正文 17px，摘要、环节正文、提示框、术语释义 16px，表格 15px，图注与页脚 14px，卡片内边距收窄；SVG 图保持 760px 宽，在图框内横向滑动，不再缩到看不清。

`check_report.py` 新增 FAIL「手机端声明」：缺 viewport 不许交付。历史报告重跑 `finalize.py` 会在这一项报 FAIL，把模板的文档头和手机端样式同步过去即可。

### 4. 优化: 浅色配色

页面底色 `#F5F6F4` 改 `#FCFCFC`，分隔线 `#DCE0DC` 改 `#E8E9E8`，去掉原先偏灰绿的底。金色 `#A67C3D` 改 `#B8912E`，浅金底与提示框同向微调。深色主题不变。

### 5. 优化: 不出 PDF

交付步骤删去询问导 PDF、无头 Chrome 命令与分页检查，交付物只有 HTML 单文件和 `figures/`。
