# 0.1.2 联网补公开数据与 PDF 交付

> 2026-07-14

---

## 详情

**产出物**
- 交付物改为 HTML + `figures/` + **PDF**，不再输出 markdown。PDF 为最后一步，由 HTML 导出（首选无头 Chrome `--print-to-pdf`），**每次导出前必须与用户确认内容是否定稿**。
- 独立 SVG 补 `xmlns` 属性，保证脱离 HTML 后能单独打开。

**框架与写法**
- 新增工作流程步骤「联网补公开数据」：1.2 发展阶段、1.3 业务规模两节必须结合最新权威公开数据来写，不能只凭素材——1.2 钉真实政策/事件年份，1.3 用最新年度的市场规模/主体数量/利润率等口径，数字标年份与来源；个案数据保留但标"非统计口径"，与公开大盘并置形成反差。
- framework.md 1.2/1.3 指南、自检清单同步补充上述要求。

**布局**
- 宽屏（≥1380px）下让「目录 + 正文」作为整体居中，而非只居中正文——修正正文偏左、右侧留白过多的观感。
